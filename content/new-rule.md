# 大富翁新规则

> 「备选方案」列为该条规则的替代玩法，`无` 表示没有备选。

## 地图

| 项目 | 说明 | 备选方案 |
|------|------|----------|
| 赤道 | 每次经过奖励 2000 | 出生点 |
| 北极 | 监狱：送进监狱时强制移动到这里 | 出生点的对角 |
| 印度洋 | 道具商店 | 无 |
| 大西洋 | 道具商店 | 无 |
| 玩家起点 | 赤道顺时针方向四个角，通过摇骰子决定位置，单双决定前进方向 | 固定赤道，顺时针 |

## 骰子

| 项目 | 说明 | 备选方案 |
|------|------|----------|
| 样式 | 1 枚十六面骰子 | 无 |
| 规则 | 摇到 16 可以再摇一次，连续两次 16 送进监狱 1 回合 | 取消此项 |

## 资金

| 项目 | 说明 | 备选方案 |
|------|------|----------|
| 初始资金 | 15000 = 5000×2 + 2000 + 1000×2 + 500 + 200 + 100×2 + 50 + 10×5 | 20000 |
| 赤道 | 每次经过赤道奖励 2000 | 出生点 |
| 乞丐 | 每次经过乞丐（破产玩家），施舍 500 | 取消此项 |

## 地产

| 项目 | 说明 | 备选方案 |
|------|------|----------|
| 等级 | 0 级空地，1–4 级绿色房子，5 级红色房子 | 根据房契 |
| 升级费用 | 绿色：购地款的 50%，红色：购地款的 100% | 根据房契 |
| 过路费 | 空地 = 购地款×20%，绿色 = 购地款×50%×等级，红色 = 购地款×300% | 根据房契 |
| 连锁 | 同颜色的房子触发时连锁收取过路费 | 取消此项 |

## 监狱

| 项目 | 说明 | 备选方案 |
|------|------|----------|
| 规则 | 强制移动到监狱格子，跳过你的回合，无法收租，无法参与拍卖，无法使用道具 | 无 |
| 双连 | 摇到 16 可以再摇一次，连续两次 16 送进监狱 1 回合 | 取消此项 |
| 机会 | 机会牌有概率送进监狱 | 无 |
| 命运 | 命运牌有概率送进监狱 | 无 |
| 嫁祸卡 | 当你被送进监狱时，指定让另外一名玩家背锅 | 无 |
| 免责卡 | 抵消你一次送进监狱 | 无 |

## 拍卖

| 项目 | 说明 | 备选方案 |
|------|------|----------|
| 规则 | 所有人都可以参加拍卖（其他规则限定除外） | 无 |
| 拍卖条件 | 被动交钱时不够现金时，可以选择一个房子进行拍卖 | 取消此项 |
| 强制拍卖 | 某些条件会触发强制拍卖 | 无 |
| 底价 | 起拍价为房子总价的 50%，向下取整十 | 无 |
| 竞价 | 每次竞价最少加 100 | 无 |
| 成交 | 成交后房子归购买者 | 无 |
| 流拍 | 银行以起拍价收购房子，此后房子无主 | 无 |
| 拍卖所得 | 拍卖所得的 25% 上交银行，向下取整十，剩下部分归房屋所有者 | 无 |

## 道具

| 项目 | 说明 | 备选方案 |
|------|------|----------|
| 购买 | 玩家进入道具商店时，随机刷新 3 个道具以供购买 | 无 |
| 出售 | 玩家进入道具商店时，可以以半价出售持有的道具 | 无 |
| 使用 | 道具可以指定玩家所在格子的前后 3 格内使用 | 无 |

## 机会

| 项目 | 说明 | 备选方案 |
|------|------|----------|
| 规则 | 玩家进入机会格子时，随机抽取 20 张机会卡，玩家通过摇骰子决定抽取哪一张 | 无 |

## 命运

| 项目 | 说明 | 备选方案 |
|------|------|----------|
| 规则 | 玩家进入命运格子时，随机抽取 20 张命运卡，玩家通过摇骰子决定抽取哪一张 | 无 |
