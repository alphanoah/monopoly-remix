# 大富翁玩法更新

## 基本规则：
- 沿用地图
- 1个十六面骰子（1-16机会均等）
- 摇到16可以再摇一次
- 初始资金 19580 = 5000*2 + 2000*2 + 1000*3 + 500*3 + 200*3 + 100*3 + 50*3 + 10*3
- 每次路过出生点，可获得2000
- 每次路过乞丐（破产玩家），需要施舍500块

## 房子规则：
- 房子等级： 0-空地，1-3绿色，4红色（MAX）
- 1-3级绿色房子升级费用 = 购地款 * 50%
- 4级红色房子升级费用 = 购地款 * 100%
- 单格过路费
  - 空地：购地款 * 20%
  - 1-3级：购地款 * 50% * 等级
  - 4级：购地款 * 300%
- 总过路费 = 同色同归属的所有房屋的过路费的总和，向下取整十

## 监狱规则：
- 送进监狱 = 强制移动到离出生点最远的格子，跳过你的回合，无法收租，无法参与拍卖
- 连续两次摇到16送进监狱1回合
- 机会/命运牌可能送进监狱

## 拍卖规则
  - 不够钱交过路费时，可以选择一个房子进行拍卖，起拍价为房子总价的50%，向下取整十
  - 升级/购地时不能触发拍卖
  - 所有人都可以参加拍卖（监狱内玩家除外）
  - 每次最少加100
  - 流拍时，银行以起拍价收购房子，此后房子无主
  - 拍卖所得的25%上交银行，向下取整十，剩下部分归房屋所有者
