# v7 修订对照表（草稿 · 待审阅）

用法：每张牌**先列 v6 原文**，下面再列「改动 → v7」。
标色来自你在 xlsx 里填的单元格底色：**红** = 内容改，**黄** = 描述改实质未变，**白** = 未改。
单元格标了白但文字实际有变的，标色栏写成 **白\***，需要你补确认；胜率列只是 `50%` → `0.5` 的格式换算不算改动，标为「格式」。
