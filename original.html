大富翁世界之旅（银牌）说明书
来源：原版实体卡《大富翁世界之旅（银牌）》说明书照片转录。

一 准备

棋盘平放，机会和命运卡分别放置于棋盘预定位置，卡片文字面向下（3001 银牌上海滩另有欢乐卡）。参加游戏的人各取一个代表物，集中摆在起点处，并分取计分券（钱币）如下：5000 元二张、1000 元四张、500 元一张、200 元一张、100 元两张、50 元一张、10 元五张（其余统归银行保管）。银行公推一人兼任，负责保管房屋、旅馆、计分券（钱币）、房权所有权证，并办理抵押及买卖土地。

二 转盘/骰子

开始时，玩家把代表物放在起点上，然后转盘或骰子决定顺序，点数多者先行。玩家轮流转盘或掷骰，按照点数移动自己的代表物顺时针方向在棋盘上行走。每到一处，玩家即按该地点格性质，执行相关的动作（见后续说明）。代表物可同时停在一格内。

三 起点

任何人经过或停留起点，银行须给他报酬金 2000 元。

四 地产

  • 停留于未经他人购买之地产时，即有权依棋盘上规定价格购买，取得产权所有权证并公开置于面前。
  • 停留于已被人购买之地产上时，即检查该地建设之房屋及旅馆数量，依产权所有权证上规定金额付给地主过路费。
  • 停留于自己购买之地产时，可选择依产权所有权证上规定之房屋建筑费，付款给银行并拿取一幢（栋）房屋置于该地产。

五 房屋

每一地产上所建筑房屋以五幢（栋）为限，建至第五幢（栋）时，将房屋缴回银行，并改以放置一幢（栋）旅馆（红色房屋）作为标志。

六 命运及机会

任何人移动到命运或机会格时，应翻阅对应之命运或机会卡一张，并按照卡上指示办理，随后将该卡放置于卡片堆底下。若该卡为「出狱许可证」，得由翻阅者保留使用或出售给他人。

七 所得税、财产税及其他税金或罚款

一律缴给银行。

八 监狱进牢

（该条款仅适用于 3001 银牌上海滩，若非该款产品请忽略此条例）

入狱条例有二：

  1. 代表物停在（进牢）。
  2. 抽到（进牢）的卡片。

进牢者请移动至坐牢的角落格，仍照常扭动转盘或掷骰。

出牢条例有二：

  1. 在入狱后的三次转/掷数字中，只要有一次能出现 10 点或以上者，即可立即出狱。
  2. 使用出狱许可证，即可立即出狱。（可向别人购买，价格自议）。

九 地产抵押

玩家手头拮据时，可随时将地产向银行抵押贷款。贷款金额按照产权所有权证背面所记载之抵押价格，向银行拿取现金。已抵押之地产，请将产权所有权证正面向下置于抵押人面前以资识别。（已抵押之地产不得收取过路费）。

抵押所有权人想要赎回地产时，需要向银行缴回抵押所得之贷款金额，并支付贷款金额百分之十利息。（赎回抵押可随时为之。）

十 地产出售

手头拮据时，除了可抵押地产，玩家也可选择向银行出售物业。房屋出售时依照原建筑费用，取回一半金额。出售旅馆时，可先将旅馆换回五幢（栋）房屋再逐幢（栋）出售。当地产上已无任何房屋，则可按照地价之半价出售予银行。（抵押中之地产不可出售。）

十一 破产

任何人无论何时，当其无力清偿应支付款项时，不论数目多寡即谓之「破产」。宣告破产时，将其剩余之计分券（钱币）全数交由债主，退出游戏。最后一位未退出游戏者即为「大富翁」（游戏的赢家！）。

十二 其他

  1. 担任银行之玩家仅协助办理地产、房屋买卖及抵押等金额点算确认，不可与其他玩家私下互相借贷影响游戏公平。
  2. 若游戏时间太长，想要提早结束者，可共同订立一个目标，例如手上现金先达到 30000 元或 50000 元的玩家，即成为大富翁并赢得游戏胜利。
  3. 游戏内附之计分券（钱币）、房屋等配件若有数量不足，可自行选择其他配件取代。

五、常见问题 FAQ

Q1：怎么判断有没有集齐一组？

集齐同一颜色的所有地产格即可。例如红色组包含中国、日本、韩国、澳大利亚、新西兰，必须全部拥有才算集齐。

Q2：同色但不连续也算一组吗？

算。大富翁的规则是按颜色分组，跟位置无关。即使某一组被机会格、海洋格或角落格隔开，只要颜色相同就是同一组。

Q3：为什么有的颜色组有 5 格、有的只有 4 格？

这是地图本身的设计。经典大富翁里也是 2~3 格不等，这里最多 6 格、最少 4 格（见上面的分组表）。

Q4：海洋格有什么用？

类似于经典大富翁的「社区福利」或「税务」格子，具体效果看游戏规则设定。数据中标记为「海洋」类型的特殊格子。

Q5：格号是怎么编的？

从起点（赤道 #0）开始，按行进方向编号：底行 → 左行 → 顶行 → 右行，回到起点。四个角落分别是 #0（赤道）、#16（地中海）、#32（北极）、#48（夏威夷）。

Q6：「浅蓝」和「深蓝」、「浅绿」和「绿」、「粉红」和「粉」有什么区别？

是完全不同的颜色组。色带深浅有明显区别，属于各自独立的颜色组，不能互相替代。

Q7：为什么红色组分散在好几处？

这是这张「世界之旅」地图的设计特点——那几个国家地理上都在亚太地区，但在棋盘上被机会格和右行终点隔开了。规则上它们仍属于同一颜色组。

六、开发参考

6.1 去哪儿拿数据

source/remix/map.json，结构如下（字段名照抄，别自己另造一份）：

`javascript
const data = {
board: { size, printMM, goBonus, trackWidth, band, tilesPerSide, corners },
layout: { property, deck, ocean, id, corner }, // 版式参数，改这里调留白
decks: { chance: {...}, fate: {...} }, // 机会/命运牌堆的配色与文案
colorGroups: [{ id, key, name, nameEn, hex, icon }], // 地产格用 colorId 引用
tileTypes: { property: {...}, chance: {...}, ... },
tiles: [{ id, type, name, nameEn, flag?, capital?, price?, colorId?, color?, side, col, row }], // flag：地产格的国旗 emoji，页面直接画
};
`

色值只在 colorGroups[].hex 出现一次，机会/命运的色通过 tileTypes[].deck 指回 decks，别在别处再写一遍颜色。

连续段数按 id 排序后，相邻差 1 算同一段
总地价所有 type:"property" 的 price 求和
