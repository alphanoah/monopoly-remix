## 五、常见问题 FAQ

### Q1：怎么判断有没有集齐一组？
集齐同一颜色的**所有**地产格即可。例如红色组包含中国、日本、韩国、澳大利亚、新西兰，必须全部拥有才算集齐。

### Q2：同色但不连续也算一组吗？
算。大富翁的规则是**按颜色分组**，跟位置无关。即使某一组被机会格、海洋格或角落格隔开，只要颜色相同就是同一组。

### Q3：为什么有的颜色组有 5 格、有的只有 4 格？
这是地图本身的设计。经典大富翁里也是 2~3 格不等，这里最多 6 格、最少 4 格（见上面的分组表）。

### Q4：海洋格有什么用？
类似于经典大富翁的「社区福利」或「税务」格子，具体效果看游戏规则设定。数据中标记为「海洋」类型的特殊格子。

### Q5：格号是怎么编的？
从起点（赤道 #0）开始，按行进方向编号：底行 → 左行 → 顶行 → 右行，回到起点。四个角落分别是 #0（赤道）、#16（地中海）、#32（北极）、#48（夏威夷）。

### Q6：「浅蓝」和「深蓝」、「浅绿」和「绿」、「粉红」和「粉」有什么区别？
是**完全不同的颜色组**。色带深浅有明显区别，属于各自独立的颜色组，不能互相替代。

### Q7：为什么红色组分散在好几处？
这是这张「世界之旅」地图的设计特点——那几个国家地理上都在亚太地区，但在棋盘上被机会格和右行终点隔开了。规则上它们仍属于同一颜色组。

## 六、开发参考

### 6.1 去哪儿拿数据

`source/map-print-data.json`，结构如下（字段名照抄，别自己另造一份）：

```javascript
const data = {
  board:    { size, printMM, goBonus, trackWidth, band, tilesPerSide, corners },
  layout:   { property, deck, ocean, id, corner },      // 版式参数，改这里调留白
  decks:    { chance: {...}, fate: {...} },             // 机会/命运牌堆的配色与文案
  colorGroups: [{ id, key, name, nameEn, hex, icon }],  // 地产格用 colorId 引用
  tileTypes:   { property: {...}, chance: {...}, ... },
  tiles:    [{ id, type, name, nameEn, flag?, capital?, price?, colorId?, color?, side, col, row }],   // flag：地产格的国旗 emoji，页面直接画
};
```

**色值只在 `colorGroups[].hex` 出现一次**，机会/命运的色通过 `tileTypes[].deck` 指回 `decks`，别在别处再写一遍颜色。

### 6.2 常用计算

这些不用手算，跑一次 `python3 tools/build.py`，本页表格、首页「数据速览」都会同步：

| 计算项 | 怎么算 |
|--------|--------|
| 某组的格数 | `tiles.filter(t => t.colorId === gid).length` |
| 某组的均价 | 该组 `price` 求平均 |
| 连续段数 | 按 id 排序后，相邻差 1 算同一段 |
| 总地价 | 所有 `type:"property"` 的 `price` 求和 |
| 一圈总格数 | `tilesPerSide × 4 + corners` |
