# 大富翁新规则 v3

> **v3 调整思路**：在 v2 基础上补全「破产 / 胜利条件」闭环，修复实测确认的「坐牢免费」与道具上限问题，抽卡改为 16 张牌池 + 掷骰点选；升级回归原版「踩到自己地才能买/升」。标注【建议】的条款为配套修订，起因写在各条括号里，全部实测数据见 `docs/balance-v7.md` 与 `docs/rule-v2-review.md`。
> 「备选方案」列为该条规则的替代玩法，`无` 表示没有备选。

## 破产（v3 新增）

- **触发**：任何时候现金 + 拍卖筹资仍不足以清偿应付款，即宣告破产（沿用原版第十一条）
- **清算**：名下房产逐一强制拍卖（起拍价 = 总价 50% 向下取整十，流拍归银行），拍卖所得按 75%/25% 结算后，连同全部剩余现金交给债主；债主为多人的，按欠款比例分配
- **缺口**：清偿后仍有缺口的，由债主自担，不向其他玩家追索
- **归属**：破产玩家退出游戏，未清算的空地全部变无主
- **说明**：本版**无抵押贷款与半价售房**（原版第九、十条不使用），应急变现手段 = 拍卖 + 道具商店半价回售
- 【建议】留场玩法（不推荐）：破产者不退出，棋子留在原地变「乞丐」——不掷骰、不参与拍卖、名下地全部无主；其他玩家经过其所在格时向银行缴 500，乞丐同时从银行领 500 救济；游戏结束时乞丐按剩余现金参与排名

## 胜利条件（v3 新增）

| 项目 | 说明 | 备选方案 |
|------|------|----------|
| 标准 | 最后未破产的玩家获胜（沿用原版第十一条） | 无 |
| 加速【建议】 | 约定回合上限（建议 **150 回合**），到达后按「现金 + 名下房产已投入成本（购地价 + 已花升级费）」排名，最高者获胜 | 无 |
| 现金目标【建议】 | 开局约定现金目标（如 50,000），最先达成者获胜（沿用原版第十二条） | 无 |

> 起因：8 人局实测平均 241 回合 / 979 次行动 ≈ 真人 5.4~12.2 小时，98% 打到只剩一人；首次破产中位第 52 回合，150 回合时局势已完全明朗。
