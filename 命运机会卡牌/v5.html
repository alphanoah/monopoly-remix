命运牌 & 机会牌 · v5（邪恶版）

  • 版本：v5（2026-10-09）
  • 基于：v4 + 邪恶版草案（用户定稿）
  • 规模：机会牌 20 张 + 命运牌 20 张，共 40 张
  • 金钱单位：游戏内「钱」，与初始资金 19580 配套
  • 设计目标
    • 结构与 v4 完全一致：机会牌 70% 奖励（14 奖励 + 6 惩罚），命运牌 20 张全部条件判定，期望奖励率 ≈ 50%
    • 邪恶的是味道，不是数值：损人利己、背叛诅咒、玩家间转移大量增加（约 15 张直接坑具体某个人），适合熟人互坑局
    • 每张牌事件与判定方式强关联：故事里就交代了「为什么要摇骰、为什么要这么押」

v5 相对 v4 的变更

  • 机会牌 20 张全部重写：奖励从「天上掉钱」变成「损人利己」（举报、出千、下药、收智商税），多张带连带受害者
  • 命运牌 20 张事件全部黑化：判定机制与 v4 完全一致（押大小 / 押单双 / 比点数 / 移动骰 / 猜左右手 / 石头剪刀布 / 押区间 / 赌爆点 / 押「不摇到 1」/ 猜数字 / 他人代摇 / 所在格奇偶+骰点），故事换成魔鬼、死神、巫婆、巨龙、魔王税务局
  • 新增两类软控制效果：禁言类（禁止交易谈判）、减益类（过路费收入减半）
  • 新增可选软规则：被点名豁免（防止 8 人局轮番坑同一个人）

通用判定规则

  • 十六面骰 1-16，等概率；移动骰摇到 16 可再摇一次
  • 判定骰与移动骰分开摇，用同一颗十六面骰；判定时摇到 16 不触发「再摇一次」
  • 零期望原则：每张命运牌（近似）满足「赢的概率 × 赢的金额 = 输的概率 × 输的金额」，命运牌整体期望 ≈ 0
  • 点名规则：
    • 「最有钱的玩家」= 现金最多者；并列时取顺时针方向最近的
    • 「最近的玩家」= 棋盘上顺时针离你最近的
    • 「左手 / 右手玩家」= 按座位紧邻的玩家
  • 被点名豁免（建议规则）：同一玩家若连续两个回合被邪恶牌点名（被抢 / 被占 / 被拍卖），第二个回合可宣布豁免，改为结算 ±500
  • 房屋规则衔接：房屋 -1 级时，1 级 → 空地（地基仍在，可从 1 级重新升）；名下无房时按牌面金额结算
  • N = 存活玩家人数（含自己）
  • 平局重来：比点数、石头剪刀布出现平局时重来一次
  • 等效金额换算（非金钱惩罚的估值用）：进监狱 1 回合 ≈ 1000，原地停止 / 躺尸 1 回合（含不收租）≈ 1000~1500，取消一次掷骰 ≈ 500~1000
  • 「回出生点（没有奖励）」= 直接送回出生点，不触发路过出生点的 +2000
